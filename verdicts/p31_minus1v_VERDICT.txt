WHY THIS DECIDES MAJORITY, NOT JUST MARGIN<=3
--------------------------------------------------------------------------
The sweep ran at --max-margin 3.  That is nevertheless a MAJORITY verdict, by
the 3-cycle bound of Section 3:

  In a 3-cycle u->v->w->u any LINEAR order agrees with at most 2 of the 3 arcs,
  so over k voters  c(u,v)+c(v,w)+c(w,u) <= 2k = 10.  Majority forces each term
  >= 3, hence no support exceeds 4.  An arc in ANY 3-cycle can never be
  unanimous, so majority == margin<=3.

Measured on THIS host rather than assumed: every arc of p31_minus1v.bits lies in
at least 7 cyclic triangles -- which is (q-3)/4 at q = 31 -- and 0 arcs lie in
none.  So margin<=3 and majority are THE SAME QUESTION here, and the refutation
above is a refutation at majority.

--------------------------------------------------------------------------
MIXED REGIME: 406 STATES WITHOUT THE BREAK, 7,625 WITH IT, STILL COMPLETE
--------------------------------------------------------------------------
--toporb 0 2 was turned on part-way through, on 2026-09-09.  The union is still
a complete refutation.  Let W be any witness.  The break is sound here, so some
g in Aut(P31-v) carries W to a witness W' = gW in which some voter ranks 0 or 2
first.  W' lies in exactly one base state B, because the base states partition
the profile space.  Two cases:

  * B was settled WITHOUT the break -- then B was searched exhaustively, so it
    contains no witness at all, contradicting W' in B;
  * B was searched WITH the break -- then W' satisfies the break by construction,
    so it lies inside the searched region.

Either way a witness cannot hide.  Note the direction: an exhaustive search of a
base state is strictly STRONGER than a broken one, so turning a sound break on
later never invalidates earlier work -- only the reverse would.  Each marker
records which regime produced it in its brk= field, so the mixture is visible in
the record rather than implicit.

CONCLUSION
--------------------------------------------------------------------------
Paley(31) is not 5-inducible (settled 2026-09-03: 5253/5253 chunks UNSAT, 0
capped, coverage [0,21009) exact, 26.89 core-h).  Vertex-criticality would
require every one-vertex deletion to BE 5-inducible.  |Aut(Paley(31))| = 465 =
C(31,2) = the number of arcs, so Aut is regular on arcs and in particular
transitive on vertices; all 31 deletions are isomorphic and one run settles them
all.  That run is UNSAT.  Hence Paley(31) is NOT vertex-critical.

Margin 1 was already refuted for this host (m1_family cell p31mv: 2200/2200 base
states, exact coverage, no witness, 2.21 core-h), so Paley(31) is not vertex-
critical at EITHER margin, and by "arc-critical implies vertex-critical" it is
not arc-critical at either margin.

What it does NOT give: any improvement to N(5) <= 23.  Non-inducibility
propagates upward, and 30 > 23.
