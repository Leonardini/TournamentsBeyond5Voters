--------------------------------------------------------------------------
WHY THIS DECIDES MAJORITY, NOT JUST MARGIN<=3
--------------------------------------------------------------------------
The sweep ran at --max-margin 3.  That is nevertheless a MAJORITY verdict, by
the 3-cycle bound (RESEARCH_LOG.md 2026-09-04 08:30):

  In a 3-cycle u->v->w->u any LINEAR order agrees with at most 2 of the 3 arcs,
  so over k voters  c(u,v)+c(v,w)+c(w,u) <= 2k = 10.  Majority forces each term
  >= 3, hence no support exceeds 4.  An arc in ANY 3-cycle can never be
  unanimous, so majority == margin<=3.

Every arc of Paley(43)-v lies in 10 three-cycles (minimum over arcs; 0 arcs lie
in none).  So margin<=3 and majority are THE SAME QUESTION here, and the
refutation above is a refutation at majority.

--------------------------------------------------------------------------
CONCLUSION
--------------------------------------------------------------------------
Paley(43) is not 5-inducible (already known, 2026-07-10).  Vertex-criticality
would require every one-vertex deletion to BE 5-inducible.  Paley(43) is
vertex-transitive, so all 43 deletions are isomorphic and one run settles them
all.  That run is UNSAT.  Hence Paley(43) is NOT vertex-critical.

This REFUTES the conjecture that Paley(43) is vertex-critical.

What it does NOT give: any improvement to N(5) <= 23.  Non-inducibility
propagates upward, and 42 > 23.
